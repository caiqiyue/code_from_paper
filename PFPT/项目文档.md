# PFPT 项目文档

## 项目概述

PFPT (Probabilistic Prompt-based Federated Training) 是一个基于概率化 Prompt 聚合的联邦学习算法实验框架。该项目实现了多种联邦学习算法与 Prompt 技术的结合，用于研究联邦场景下的视觉任务。

## 模块功能详解

### 1. main.py - 主程序

**功能**: 项目主入口，负责参数配置、数据加载、模型初始化和训练流程控制。

**主要参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--alg` | fedavg | 算法名称: fedavg/fedprox/fedopt/scaffold/fedavg_gmm/pfedpg/fedavg_nonpara |
| `--dataset` | cifar10 | 数据集: cifar10/cifar100/PACS/tinyimagenet/fourdataset |
| `--device` | cuda | 设备: cuda/cpu |
| `--batch` | 64 | 批大小 |
| `--comms` | 100 | 通信轮数 |
| `--local_eps` | 5 | 本地训练轮数 |
| `--lr` | 5e-5 | 学习率 |
| `--n_clients` | 100 | 客户端数量 |
| `--n_sampled_clients` | 10 | 每轮采样的客户端数 |
| `--data_distribution` | non_iid_dirichlet | 数据分布: non_iid_dirichlet/manual_extreme_heterogeneity |
| `--alpha` | 0.3 | Dirichlet 非IID 分布参数 |

### 2. Algo/ - 联邦学习算法

#### 2.1 fedavg.py - FedAvg 算法

**类**: `fedavg(nn.Module)`

**功能**: 实现 FedAvg (Federated Averaging) 基础算法。

**核心方法**:
- `client_train()`: 本地训练客户端模型
- `server_aggre()`: 服务器端聚合模型
- `server_eval()`: 服务器端评估

**训练流程**:
1. 随机选择参与本轮通信的客户端
2. 各客户端在本地数据上训练多个 epoch
3. 服务器加权聚合客户端模型参数

#### 2.2 fedprox.py - FedProx 算法

**类**: `fedprox(fedavg)`

**功能**: 在 FedAvg 基础上添加近端项正则化，解决非IID数据导致的客户端漂移问题。

**额外参数**:
- `mu`: 近端项系数，控制本地模型与全局模型接近程度

#### 2.3 fedopt.py - FedOpt 算法

**类**: `fedopt(fedavg)`

**功能**: 使用自适应优化器进行服务器端更新，类似于 FedAdam/FedAdagrad。

**额外参数**:
- `fedopt_global_lr`: 全局模型更新学习率

#### 2.4 scaffold.py - SCAFFOLD 算法

**类**: `scaffold(fedavg)`

**功能**: 引入控制变量 (control variates) 纠正客户端漂移，需要维护每个客户端的个性化模型。

**特点**:
- 维护服务器端控制变量 `c`
- 维护客户端控制变量 `c_i`
- 使用控制变量梯度修正

#### 2.5 communication.py - 聚合通信模块

**函数**: `communication(server_model, models, client_weights, fed_method, ...)`

**功能**: 根据不同 `fed_method` 执行模型聚合。

**支持的聚合方法**:

| fed_method | 说明 |
|------------|------|
| `fedavg` | 标准加权平均 |
| `fedbn` | 仅 BatchNorm 层本地更新 |
| `scaffold` | SCAFFOLD 聚合 |
| `simple_gmm_prompt` | GMM 聚合 Prompt 参数 |
| `nonparametric_aggregation` | 非参数化聚合 |

**GMM Prompt 聚合 (`simple_gmm_prompt`)**:
- 对 prompt 参数使用贝叶斯高斯混合模型 (Bayesian GMM) 聚合
- 其他参数使用标准加权平均

**非参数聚合 (`nonparametric_aggregation`)**:
- 使用神经网络学习聚合权重
- 训练 `cov_net` 和 `bernoulli_net`
- 基于似然估计进行优化

#### 2.6 nonparametric_aggregation.py - 非参数聚合

**类**: `NonparametricAgg(nn.Module)`

**功能**: 实现基于概率模型的可学习聚合方法。

**网络结构**:
- `cov_net`: 学习每个簇的协方差矩阵
- `bernoulli_net`: 学习簇存在概率

**算法流程**:
1. 初始化聚类中心 (质心)
2. 交替优化: 更新网络参数 φ 和分配矩阵 z
3. 使用 `linear_sum_assignment` 求解最优分配
4. 聚合选中的 prompt

### 3. Models/ - 模型架构

#### 3.1 Prompted_models.py - Prompted ViT-B/32

**类**: `Prompted_ViT_B32(nn.Module)`

**功能**: 在预训练 ViT-B/32 基础上添加可学习的 Prompt。

**模型结构**:
```
输入图像
  ↓
ViT-B/32 特征提取 (冻结)
  ↓
Prompt Embeddings (可学习, num_tokens × 768)
  ↓
拼接 [CLS] token + Prompts + Patch tokens
  ↓
Transformer Encoder
  ↓
分类头 (MLP: 768→512→num_classes)
```

**Prompt 方法**:
- `shallow`: 仅在输入层添加 prompt
- `deep`: 在每个 Transformer 层都添加 prompt

**组件**:
- `prompt_embeddings`: 可学习 prompt 参数
- `deep_prompt_embeddings_list`: 深层 prompt (仅 deep 模式)
- `classification_head`: 两层 MLP 分类器

#### 3.2 L2P_heuristic_model.py - L2P 模型

**类**: `L2P_ViT_B32(nn.Module)`

**功能**: Learn to Prompt (L2P) 方法，使用可学习的 prompt pool 和键值查询机制。

**模型结构**:
```
输入图像
  ↓
ViT 提取 CLS features
  ↓
Prompt Pool (可学习, pool_size × 768)
  ↓
键值匹配: Query(CLS features) vs Keys(Prompt Pool)
  ↓
选择 top_k 个最相关 prompts
  ↓
拼接并输入 Transformer
  ↓
分类头
```

**核心组件**:
- `Pool`: Prompt 池管理器
  - `prompt`: 可学习 prompt 池
  - `features_proj`: 特征投影层
  - `top_k`: 每次选择的 prompt 数量
  - `batchwise_prompt`: 是否按批次选择

- `trained_prompts_checklist`: 记录每个 prompt 被使用的频率

#### 3.3 pFedPG_model.py - pFedPG 模型

**功能**: 个性化联邦提示生成器，每个客户端有专属的 prompt。

**组件**:

1. **`client_prompted_vit_b32`**: 客户端 ViT 模型
   - 包含可学习的 `prompt_embeddings`
   - 接收个性化的 prompt 进行前向传播

2. **`prompt_generator`**: Prompt 生成器
   ```
   Base Prompts (可学习) + Client Descriptor (Embedding)
        ↓
   Q (来自 Client Descriptor), K, V (来自 Base Prompts)
        ↓
   Attention 机制
        ↓
   生成的个性化 Prompt
   ```

3. **`BaseHeadsForLocal`**: 本地分类头
   - 每个客户端有独立的分类层
   - 允许个性化分类决策

### 4. data_util/ - 数据处理

#### 4.1 DataDistributer.py - 数据分区器

**类**: `DataPartitioner`

**功能**: 将数据集分配给多个客户端。

**分配方法**:

1. **Dirichlet 非IID分布** (`dirichlet_split_noniid`):
   - 使用 Dirichlet 分布分配各类别数据
   - `alpha` 参数控制非IID程度
     - alpha 小 → 数据分布差异大
     - alpha 大 → 数据分布接近IID

2. **手动极端异构** (`manual_allocating_noniid`):
   - 指定每个客户端主导的类别数量
   - `n_dominated_classes_per_client`: 每客户端主导类别数
   - `dominated_ratio`: 主导类别数据占比

**方法**:
- `get_distributed_data()`: 返回各客户端的 DataLoader
- `get_all_client_weights()`: 返回各客户端数据量权重

#### 4.2 Four_dataset_reader.py - 四数据集读取器

**数据集组成**:
| 数据集 | 类别范围 | 说明 |
|--------|----------|------|
| MNIST-M | 0-9 | 带有背景的 MNIST |
| Fashion-MNIST | 10-19 | 时尚物品分类 |
| CINIC-10 | 20-29 | ImageNet 子集 |
| MMAFEDB | 30-36 | 移动加速计手势 |

**类别掩码** (`class_mask`):
- 用于支持多域学习，每个子数据集有独立的类别集合

#### 4.3 PACS_reader.py - PACS 数据集

**域**:
- Art Painting
- Cartoon
- Photo
- Sketch

每个域作为一个"客户端"，用于域泛化研究。

#### 4.4 TinyImageNet_reader.py - TinyImageNet

- 200 个类别
- 64×64 图像
- 用于大规模分类任务

### 5. util/ - 工具函数

#### 5.1 train_eval.py - 训练与评估

**核心函数**:

| 函数 | 功能 |
|------|------|
| `train()` | 标准模型训练 |
| `evaluate()` | 模型评估 |
| `evaluate_mask()` | 带类别掩码的评估 |
| `train_prox()` | FedProx 训练 (含近端项) |
| `train_scaffold()` | SCAFFOLD 训练 (含控制变量梯度修正) |
| `train_eval_pFedPG()` | pFedPG 完整训练流程 |
| `evaluate_pFedPG()` | pFedPG 模型评估 |

**pFedPG 训练流程**:
1. 随机选择一个客户端
2. 使用 prompt_generator 为该客户端生成个性化 prompt
3. 固定 prompt，训练 ViT 和本地分类头 (多个 epoch)
4. 计算 prompt 参数的梯度，更新 prompt_generator

- `save_model_trainable_part()`: 保存模型可训练部分
- `save_pfedpg_baseHeads()`: 保存 pFedPG 本地分类头

## 算法流程

### 标准联邦学习流程 (FedAvg/FedProx/FedOpt/SCAFFOLD)

```
┌─────────────────────────────────────────────────────────────┐
│                        服务器端                              │
│  1. 初始化全局模型 (ViT-B/32 + Prompt)                       │
│  2. 分发全局模型给选中的客户端                                │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                      客户端本地训练                           │
│  for epoch in range(local_eps):                             │
│      for batch in local_data:                               │
│          loss = Loss(model(batch), labels)                 │
│          if FedProx:                                       │
│              loss += mu/2 * ||w - w_global||^2            │
│          if SCAFFOLD:                                      │
│              loss += (c - c_i) · w                        │
│          optimizer.step()                                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                        服务器端聚合                           │
│  w_global = Σ (n_k / N) * w_k                              │
│  if GMM: 对 prompt 使用 GMM 聚合                           │
│  if Nonparametric: 使用神经网络学习聚合                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    (重复通信轮次)
```

### pFedPG 流程

```
┌─────────────────────────────────────────────────────────────┐
│                        服务器端                               │
│  维护: prompt_generator, global ViT                          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                      客户端个性化训练                         │
│  1. 根据 client_id 生成个性化 prompt                        │
│  2. 本地训练 ViT + 分类头                                   │
│  3. 计算 prompt 梯度，反向传播到 generator                  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                      服务器端更新                             │
│  更新 prompt_generator 参数                                  │
└─────────────────────────────────────────────────────────────┘
```

## 算法变体对照表

| 算法 | 聚合方式 | Prompt处理 | 特点 |
|------|----------|------------|------|
| FedAvg | 加权平均 | 简单平均 | 基础算法 |
| FedAvg + GMM | GMM聚类 | GMM聚合 | 软聚类聚合 |
| FedAvg + Nonpara | 神经网络 | 非参数聚合 | 可学习聚合 |
| FedProx | 加权平均 | 近端项正则 | 防止漂移 |
| FedOpt | 自适应优化 | 自适应更新 | Adam风格 |
| SCAFFOLD | 控制变量 | 漂移校正 | 方差缩减 |
| pFedPG | 个性化 | 提示生成器 | 完全个性化 |
