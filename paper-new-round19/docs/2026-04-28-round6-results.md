## 关键发现

### 1. 所有 40 个实验结果完全相同 — override 疑似未生效

**异常现象**: c01-c10 覆盖 λ_generic=[0.35, 0.30, 0.25, 0.20, 0.15, 0.10, 0.05, 0.01] 和 λ_redundancy=[0.20, 0.15]，但所有 40 个实验产生了**完全相同的结果**。

**可能原因**:
1. override 代码在 `stage1_runner.py` 中存在，但 config 加载时 override 值没有被正确读取
2. config 验证（validate_only）可能在实际运行前就完成了，导致 override 被跳过
3. config 加载路径可能存在问题

**验证结果**:
- Python 直接加载 config 确认 `_forums_lambda_generic: 0.15` 和 `lambda_generic: 0.35` 均存在于 `selector_cfg` 中
- `dataset_name` 在 leaf config 中正确设置为 "forums"

### 2. 基础参数与 g1 不同

Round 6 base config (`gate_low=0.78, gate_high=0.90, mid_scale=0.45`) 与 Round 5fin g1 结果不一致:
| 数据集 | Round 6 (g1 gate) | Round 5fin g1 |
|--------|-------------------|---------------|
| jobs | 0.2761 | 0.2770 |
| forums | 0.2471 | 0.2500 |
| microblog | 0.2749 | 0.2737 |
| congressional | 0.2970 | 0.2970 |

### 3. forums 仍未突破 PrE-Text 基线 (0.2501)

无论 λ_generic 如何变化，forums 始终为 0.2471，与 g1 的 0.2500 差距明显。

### 4. jobs / microblog / congressional 稳定超越基线

- jobs: 0.2761 > 0.2718 (+0.0043)
- microblog: 0.2749 > 0.2683 (+0.0066)
- congressional: 0.2970 > 0.2906 (+0.0064)
