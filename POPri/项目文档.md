# POPri: Private Federated Learning using Preference-Optimized Synthetic Data

## 1. 项目概述

**POPri (Policy Optimization for Private data)** 是一个将合成数据生成重新定义为强化学习（RL）问题的差分隐私联邦学习算法。该项目实现了 ICML 2025 论文 [POPri: Private Federated Learning using Preference-Optimized Synthetic Data](https://arxiv.org/pdf/2504.16438)。

### 核心思想
通过偏好优化（Preference Optimization）生成高质量的差分隐私（DP）合成数据，用于下游任务训练，显著提升了完全隐私设置下的模型实用性。

## 3. 模块功能详解

### 3.1 `generate_samples.py` - 合成样本生成
**功能**: 使用 LLM（vLLM推理引擎）基于提示模板生成合成样本

**关键流程**:
1. 加载基础数据集（3个样本作为few-shot示例）
2. 使用 `meta-llama/Meta-Llama-3-8B` 模型生成合成文本
3. 对生成文本进行截断处理（默认64 tokens）
4. 保存生成的样本和对应的提示集

**主要参数**:
- `num_pref_pairs`: 偏好对数量（默认1800）
- `rank_samples`: 每个提示的采样数量（默认10）
- `temperature`: 采样温度（默认1.0）
- `max_tokens`: 最大生成长度（默认85）

### 3.2 `client_feedback.py` - 客户端反馈计算
**功能**: 计算合成样本与客户端数据的相似度评分，构建偏好数据集

**关键流程**:
1. 使用 `all-MiniLM-L6-v2` 句子嵌入模型编码所有文本
2. 计算合成样本与客户端数据的余弦相似度
3. 添加差分隐私噪声（`privacy.noise` 参数）
4. 对每个提示生成的多个样本进行排序
5. 构建偏好对（chosen/rejected），其中被拒绝样本的排名由 `reject_rank` 指定

**核心函数**: `neural_scores_for_policy()` - 基于神经嵌入模型的评分函数

### 3.3 `dpo_training.py` - DPO训练
**功能**: 使用直接偏好优化（Direct Preference Optimization, DPO）训练LLM

**关键配置**:
- 使用 LoRA 微调（r=16, lora_alpha=16）
- 目标模块: q_proj, o_proj, v_proj, k_proj, gate_proj, up_proj, down_proj
- 学习率: 余弦退火（默认 start_lr=8e-07, end_lr=8e-07）
- Dropout: 0.1
- 使用 `trl` 库的 DPOTrainer 实现

### 3.4 `model_merge.py` - 模型合并
**功能**: 将 LoRA 适配器与基础模型合并

**流程**:
1. 加载基础模型和最新检查点
2. 使用 `PeftModel.from_pretrained()` 加载LoRA权重
3. 调用 `merge_and_unload()` 合并模型
4. 保存合并后的模型和配置

### 3.5 `generate_samples_eval.py` - 评估样本生成
**功能**: 使用训练好的模型生成用于FID评估的样本

**与 `generate_samples.py` 的区别**:
- 使用合并后的模型（而非基础模型）
- 生成结果用于后续的FID评估

### 3.6 `evaluation.py` - 评估模块
**功能**: 计算Fréchet Inception Distance (FID) 评估生成质量

**评估指标**:
- **FID**: 基于均值和协方差的分布距离
- **MSE**: 基于均值的距离

### 3.7 `downstream_eval.py` - 下游任务评估
**功能**: 在合成数据上训练下游模型，评估生成数据的实用性

**流程**:
1. 使用训练好的生成器模型合成训练数据
2. 在合成数据上微调 DistilGPT2 模型
3. 在真实评估集上计算 next-token prediction 准确率
4. 报告 Top-1, Top-3, Top-5 准确率

### 3.8 `privacy_accountant.py` - 隐私预算计算
**功能**: 使用 RDP（Rényi Differential Privacy）分析器计算隐私预算

## 4. 算法流程

### 4.1 整体训练循环（30轮）

```
for round in [0, 1, ..., 30]:
    1. generate_samples.py      # 生成合成样本
    2. client_feedback.py       # 计算偏好反馈（添加DP噪声）
    3. dpo_training.py          # DPO训练更新模型
    4. model_merge.py           # 合并LoRA与基础模型
    5. generate_samples_eval.py # 使用新模型生成评估样本
    6. evaluation.py            # 计算FID评估指标
```

### 4.2 核心算法原理

**问题定义**:
在联邦学习场景中，每个客户端持有私有数据，如何生成高质量的差分隐私合成数据？

**解决方案**:
1. **样本生成**: 使用LLM基于few-shot提示生成合成样本
2. **偏好反馈**: 使用神经嵌入模型（句子Transformer）计算合成样本与客户端数据的相似度，添加DP噪声后排序
3. **偏好优化**: 使用DPO训练LLM，使其倾向于生成更接近客户端数据分布的样本
4. **迭代优化**: 重复上述过程，逐步提升合成数据质量

```yaml
# 基础配置
round_number: 0

  per_round_clients: 72000
```

## 7. 关键参数说明

### 7.1 差分隐私参数
| 参数 | 值 | 说明 |
|------|-----|------|
| `noise` | 19.3 | 隐私噪声乘数 |
| `per_round_clients` | 72000 | 每轮采样的客户端数量 |
| `total_clients` | 72000 | 总客户端数量 |

### 7.2 DPO训练参数
| 参数 | 值 | 说明 |
|------|-----|------|
| `beta` | 0.01 | DPO损失函数的温度参数 |
| `batch_size` | 4 | 训练批次大小 |
| `in_round_epochs` | 1 | 每轮训练的epoch数 |
| `start_lr` | 8e-07 | 初始学习率 |
| `end_lr` | 8e-07 | 最终学习率 |
| `gradient_accumulation` | 6 | 梯度累积步数 |

### 7.3 LoRA微调参数
| 参数 | 值 | 说明 |
|------|-----|------|
| `r` | 16 | LoRA秩 |
| `lora_alpha` | 16 | LoRA缩放因子 |
| `lora_dropout` | 0.0 | Dropout率 |
| `target_modules` | q_proj, o_proj, v_proj, k_proj, gate_proj, up_proj, down_proj | 目标模块 |

### 7.4 生成参数
| 参数 | 值 | 说明 |
|------|-----|------|
| `num_pref_pairs` | 1800 | 偏好对数量 |
| `rank_samples` | 10 | 每个提示的候选样本数 |
| `reject_rank` | 4 | 被拒绝样本的排名 |
| `temperature` | 1.0 | 采样温度 |
| `top_p` | 1.0 | 核采样阈值 |
| `max_tokens` | 85 | 最大生成长度 |
| `trunc_len` | 64 | 截断长度 |

## 11. 评估指标

### 11.1 合成质量指标
- **FID (Fréchet Inception Distance)**: 衡量生成分布与真实分布的距离
- **MSE (Mean Squared Error)**: 基于均值的距离

### 11.2 下游任务指标
- **Top-1/3/5 Accuracy**: Next-token prediction准确率
- **Cross Entropy Loss**: 交叉熵损失
