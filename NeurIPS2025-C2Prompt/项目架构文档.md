# C^2Prompt 项目架构文档

## 项目概述

**C^2Prompt: Class-aware Client Knowledge Interaction for Federated Continual Learning**

NeurIPS 2025 论文，来自北京大学。该项目解决联邦持续学习（Federated Continual Learning, FCL）中的类增量学习问题，在分布式客户端环境下实现跨任务的持续学习。

## 2. 核心模块功能

### 2.1 main.py（入口模块）

**功能**：
- 设置多客户端联邦学习环境
- 管理任务分发
- 通过 `FedAvg_our_v1` 实现全局模型聚合
- 协调客户端选择和训练循环

**关键参数**：
| 参数 | 说明 |
|------|------|
| `num_clients` | 客户端总数 |
| `local_clients` | 每轮选择的客户端数 |
| `epochs_global` | 全局训练轮数 |
| `tasks_global` | 每个任务的轮数 |

### 2.2 option.py（配置模块）

**关键配置项**：
```python
--num_classes          # 总类别数
--dataset              # 数据集名称 (CIFAR100, DomainNet, ImageNet_R)
--numclass             # 每任务类别数
--class_per_task       # 每任务类别数
--num_clients          # 初始客户端数（默认30）
--local_clients        # 每轮参与客户端数（默认10）
--epochs_global        # 全局轮数（默认100）
--tasks_global         # 每任务轮数（默认10）
--prompt_flag          # Prompt方法 (codap_2d_v2)
--prompt_param         # Prompt池参数 [25, 10, 10, 8, 0, 0, 6]
--global_update_lr     # 全局更新学习率
--learning_rate        # 本地学习率（默认2.0）
```

### 2.3 Fed_utils.py（联邦学习工具）

**核心函数**：

| 函数 | 功能 |
|------|------|
| `setup_seed()` | 随机种子初始化 |
| `model_to_device()` | 模型设备分配（GPU/CPU）|
| `FedAvg_our_v1()` | 自定义联邦平均，支持任务感知聚合 |
| `local_train_cprompt()` | 客户端本地训练 |
| `model_global_eval_hard()` | 全局模型评估 |
| `participant_exemplar_storing_cprompt()` | 示例管理 |
| `aggregate_proto_by_class()` | 按类聚合原型 |

### 2.4 prompt_hard.py（DualPrompt_hard 类 - 核心训练逻辑）

主要方法：

| 方法 | 功能 |
|------|------|
| `beforeTrain()` | 每轮训练前设置 |
| `train()` | 本地训练循环 |
| `_compute_loss()` | 多组件损失计算 |
| `_ntd_loss()` | 新颖性转移蒸馏损失 |
| `consolidation_train()` | 跨任务知识巩固 |
| `proto_save()` | 原型计算与存储 |
| `_construct_exemplar_set()` | 构建示例集合 |
| `_construct_exemplar_dict()` | 构建示例字典 |

### 2.5 models_Cprompt/（模型架构）

#### vit_coda_p.py - Prompt实现

实现了多种基于Prompt的方法：

| 类名 | 说明 |
|------|------|
| `DualPrompt` | 基础DualPrompt |
| `L2P` | Learn-to-Prompt |
| `CodaPrompt` | 持续Prompt描述符 |
| `CodaPrompt_2d_v2` | 扩展CodaPrompt（C2Prompt使用）|

关键组件：`e_p_share_`, `e_k_share_`, `e_a_share_` 每层Prompt

#### vit_coda_p_hard.py - 全局模型

| 方法 | 功能 |
|------|------|
| `calculate_prompt_choosing()` | 计算Prompt重要性 |
| `train_class()` | 类特定Prompt训练 |
| `updateweight_with_promptchoosing()` | 基于相似性更新Prompt权重 |
| `Incremental_learning()` | 处理任务转换 |
| `forward()` | 带Prompt路由的前向传播 |

#### vit_class.py - Vision Transformer

| 类名 | 功能 |
|------|------|
| `VisionTransformer` | 标准ViT实现 |
| `CombinedViT` | ViT与PromptModule组合 |
| `PromptModule` | Prompt池管理 |
| `Attention` | 带Prompt注入的多头注意力 |
| `Block` | 带Prompt支持的Transformer块 |

### 2.6 benchmark_metrics.py（评估指标）

计算6个核心指标：
1. **AIA** - 平均增量准确率
2. **FORGET** - 遗忘度量
3. **FORWARD** - 前向迁移
4. **BACKWARD** - 后向迁移
5. **TOTAL TRANSFER** - 总迁移量（FORWARD + BACKWARD）

## 3. 算法流程（C^2Prompt）

### 3.1 初始化阶段

1. 构建带CodaPrompt的全局Vision Transformer模型
2. 初始化可学习的Prompt池参数
3. 为每个客户端创建本地模型和数据

### 3.2 联邦训练循环

对于每个全局轮次 `ep_g`：

```
┌─────────────────────────────────────────────────────┐
│ 1. 客户端选择                                        │
│    从 num_clients 中随机选择 local_clients 个客户端   │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│ 2. 任务管理                                         │
│    每 tasks_global 轮到达新任务                      │
│    - 更新 class_distribution_client                 │
│    - 重置旧客户端                                     │
│    - old_client_0: 持有旧任务的客户端                  │
│    - old_client_1: 新任务客户端                       │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│ 3. Prompt权重更新                                    │
│    updateweight_with_promptchoosing()                │
│    - 使用 get_aqk() 计算每客户端/任务的Prompt注意力权重│
│    - 计算Prompt间的相似度用于任务选择                  │
│    - 更新 self.prompt.weight 和 self.prompt.fc_weight │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│ 4. 本地训练                                          │
│    local_train_cprompt()                             │
│    每个客户端在本地数据上训练：                         │
│    - 使用Prompt池选择相关Prompt                       │
│    - 计算多组件损失：                                  │
│      • normal_loss: 当前任务交叉熵                    │
│      • prompt_loss: Prompt多样性损失                  │
│      • ntd_loss: 新颖性转移蒸馏损失                    │
│      • control_loss: 类分离控制损失                    │
└─────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│ 5. 联邦聚合                                          │
│    FedAvg_our_v1()                                   │
│    - 客户端模型加权平均                                │
│    - 任务感知：按 global_task_id 和 class 聚合         │
│    - Prompt参数与分类器权重分别处理                     │
└─────────────────────────────────────────────────────┘
```

### 3.3 类感知知识交互

C^2Prompt的核心创新：

- 维护 `class_distribution_client` 映射客户端/任务到类别
- `class_distribution_client_real` 存储真实类别标签
- 计算 `class_features` 和 `global_class_stats` 用于原型知识迁移
- 在 `CombinedViT` 中使用对比损失进行类级表征对齐

```bash
--device 6/7
--dataset ImageNet_R
--numclass 500
--class_per_task 20
--tasks_global 3
--num_clients 5
--epochs_global 15
--prompt_flag codap_2d_v2
--method cprompt_c2prompt_v2
--prompt_param 25 10 10 8 0 0 6 10 8
--epochs_local 10
```

### 5.2 DomainNet 训练脚本（run_domainnet.sh）

```bash
--device 6
--dataset DomainNet
--numclass 1750
--class_per_task 35
--tasks_global 3
--num_clients 5
--epochs_global 15
--prompt_flag codap_2d_v2
--method cprompt_c2prompt_domainnet_v2
--prompt_param 25 10 10 8 0 0 6 10 8

```

### 5.3 关键超参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `learning_rate` | 本地学习率 | 0.005 |
| `global_update_lr` | 全局更新学习率 | 100 |
| `batch_size` | 批大小 | 32-64 |
| `prompt_param` | Prompt池参数 | [25, 10, 10, 8, 0, 0, 6] |
| `ema_global` | 原型指数移动平均 | 0.95 |

### 5.4 prompt_param 参数说明

```
[pool_size, pool_size_1, e_p_length, key_dim, ortho_mu, g_p_length]
  ↓        ↓           ↓         ↓        ↓         ↓
  25       10          10         8        0         6
```

| 索引 | 参数 | 说明 |
|------|------|------|
| 0 | pool_size | Prompt池大小 |
| 1 | pool_size_1 | 辅助池大小 |
| 2 | e_p_length | Prompt长度 |
| 3 | key_dim | 键维度 |
| 4 | ortho_mu | 正交正则化系数 |
| 5 | g_p_length | 全局Prompt长度 |

## 7. 评估指标详解

### benchmark_metrics.py 指标定义

| 指标 | 名称 | 说明 |
|------|------|------|
| AIA | Average Incremental Accuracy | 增量学习平均准确率 |
| FORGET | Forgetting Measure | 灾难性遗忘度量 |
| FORWARD | Forward Transfer | 前向迁移能力（正迁移）|
| BACKWARD | Backward Transfer | 后向迁移能力（抗遗忘）|
| TOTAL | Total Transfer | FORWARD + BACKWARD |

**评估时机**：每3轮（任务边界）计算一次

## 8. 技术总结

C^2Prompt 是一个复杂的联邦持续学习系统：

1. **基于Vision Transformer**：使用ViT作为骨干网络，配合可学习的Prompt池
2. **类增量学习**：处理跨分布式客户端的类增量学习场景
3. **类感知Prompt共享**：学习跨客户端的类别相关Prompt权重
4. **原型知识蒸馏**：使用原型基础的蒸馏防止遗忘
5. **任务感知聚合**：定制的联邦聚合尊重任务边界

### 核心创新点

- **类感知客户端知识交互机制**：学习哪些Prompt对每个类别最相关
- **跨客户端知识迁移**：在保护隐私的同时实现有效知识共享
- **新颖性转移蒸馏（NTD）**：从旧模型转移知识到新模型
