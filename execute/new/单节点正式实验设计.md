# 单节点正式实验设计

更新时间：2026-04-16

## 1. 目标

本设计只覆盖两类单节点正式实验：

1. 单节点创新算法正式实验
2. 单节点 PrE-Text 正式实验

设计原则：

- 两类方法都最终导出合成语料，再进入同一套下游任务评测
- 公平比较只对齐共同可控维度，不强行要求上游流程同构
- 单节点创新算法的 scorer / aggregator 机制消融单独成表，不与 PrE-Text 混排

## 2. 统一公平规则

### 2.1 必须对齐的维度

- 相同数据集
- 相同隐私预算
- 相同最终导出合成样本数
- 相同下游评测模型与超参数

### 2.2 上游模型规则

- PrE-Text 正式实验的 bootstrap 生成模型统一为 `llama2_7b`
- 单节点创新算法正式实验的 LLM 配置统一为 `llama_2_7b_hf`

### 2.3 下游评测口径

- 本轮正式实验统一使用 `gpt2`
- 原因：仓库内存在 `distilgpt2` 模型目录，但当前没有 `c4_checkpoint.pth`，不满足稳定的 DistilGPT2 warm-start 前置条件

### 2.4 最终导出样本数

- 单节点创新算法：`stage_b.generated_count = 1500`
- PrE-Text：`bootstrap.num_prompts = 1500`

## 3. 统一执行机制

### 3.1 单节点创新算法

统一入口：

```bash
cd /root/autodl-tmp/caiqiyue/code_from_paper
conda activate caiqiyue-vllm
python -m thesis_platform.scripts.run_experiment --config <config>
```

实现约束：

- 全部单节点正式配置使用 `execution.mode: single_node`
- 统一由 `run_experiment.py` 读取 YAML 并分发到单节点流程
- 单节点正式配置统一继承联邦同款 scorer 方法文件：
  - `datainf_real.yaml`
  - `gradmm_real.yaml`
  - `ira.yaml`

### 3.2 单节点 PrE-Text

统一入口：

```bash
cd /root/autodl-tmp/caiqiyue/code_from_paper/PrE-Text
conda activate pretext
python -m pretext_platform.scripts.run_pipeline --config <config>
python -m pretext_platform.scripts.run_eval_small --config <config>
```

执行约束：

- 正式配置统一放在 `PrE-Text/configs/experiments/single_node_formal/`
- `run_pipeline` 只负责生成语料
- `run_eval_small` 统一执行 `gpt2` 下游评测

## 6. 结果目录口径

### 6.1 单节点创新算法

- 输出根目录：`outputs/thesis_platform`
- 当前单节点目录：`outputs/thesis_platform/<experiment_id>/`
- 主要结果：`outputs/thesis_platform/<experiment_id>/metrics_summary.json`
- Stage A 结果：`outputs/thesis_platform/<experiment_id>/stage_a/`
- Stage B 合成语料：`outputs/thesis_platform/<experiment_id>/stage_b/llama7b_text_syn.json`

### 6.2 单节点 PrE-Text

- 输出根目录：`PrE-Text/outputs/pretext_platform`
- 主要结果：`<experiment_dir>/eval_small_summary.json`
- Stage 2 合成语料：`<experiment_dir>/stage2/llama7b_text_syn.json`

## 7. 推荐执行顺序

1. 先跑公平主表基线：`SN-C1/SP-C1`
2. 再跑跨数据集主表：`SN-C2~C4` 与 `SP-C2~C4`
3. 再跑隐私组：`SN-C5~C7` 与 `SP-C5~C7`
4. 最后跑单节点创新算法机制组：`SN-A1~A5`
5. 稳健性种子组 `SN-C8/C9` 与 `SP-C8/C9` 放到最后单独排队

## 8. 复用关系

- `SN-C1` 是单节点创新算法主基线，同时作为 scorer/aggregator 消融对照
- `SP-C1` 是单节点 PrE-Text 主基线，同时作为隐私和种子对照

## 9. 说明

- `probe_core.py` 本轮不删除，但单节点正式实验不再依赖它作为默认主路径
- `IRA` 单节点正式配置保持与联邦版一致，继续允许在 `raw_text` 数据上作为机制对比项使用
## 8. Stage A 迭代口径补充

- 单节点创新算法正式实验的 Stage A 固定执行 5 轮，不再因为收敛阈值提前停止。
- 如果某一轮没有产生新的规则，或者更新后的 prompt 与上一轮相同，也继续执行后续轮次，不中途退出。
- 5 轮候选 prompt 会按顺序分别生成合成数据，并串行执行 5 次下游评估，不能并行同时起多个 7B 任务。
- 最终结果按下游指标字典序选优：先比 `top1`，再比 `top3`，再比 `top5`，最后比 `top10`。
