## 三、PrE-Text 流程分析

### 3.1 PrE-Text 四阶段流程

```
Stage 1: Private Evolution (基于 RoBERTa-large 的 mask-fill 变异)
    ├── 输入: 公共初始化池 + 私有训练数据
    ├── 过程: mask-fill 变异 → 候选评分 → 直方图阈值筛选
    └── 输出: 高质量合成候选集

Stage 2: Bootstrap / Expand (基于 Llama-2-7B 的大模型扩增)
    ├── 输入: Stage1 筛选后的候选
    ├── 过程: LLM 生成更多类似样本
    └── 输出: 大规模合成训练语料 (论文: 50,000 条)

Eval Small: DistilGPT2 微调评估
    ├── 输入: Bootstrap 生成的语料
    ├── 过程: DistilGPT2 微调 20 epochs
    └── 输出: PPL (困惑度) 评估

Eval Large: LLaMA-2-7B LoRA 微调评估
    ├── 输入: Bootstrap 生成的语料
    ├── 过程: LLaMA-2-7B LoRA 微调 1 epoch
    └── 输出: PPL 评估
```

### 6.2 创建实验记录脚本

创建 `PrE-Text/scripts/log_experiment.py` 用于记录实验元信息：

```python
"""记录实验元信息和结果摘要"""
from __future__ import annotations
import json
from pathlib import Path

def log_experiment(
    experiment_id: str,
    config_path: str,
    output_dir: str,
    dataset_name: str,
    epsilon: float,
    stages_completed: list[str],
    metrics: dict,
    notes: str = ""
):
    """记录实验元信息到 JSON 文件"""
    log_path = Path(output_dir) / "experiment_log.json"
    log = {
        "experiment_id": experiment_id,
        "config_path": config_path,
        "output_dir": output_dir,
        "dataset_name": dataset_name,
        "epsilon": epsilon,
        "stages_completed": stages_completed,
        "metrics": metrics,
        "notes": notes,
    }
    with open(log_path, "w", encoding="utf-8") as f:
        json.dump(log, f, ensure_ascii=False, indent=2)
    return log_path
```
