## 八、PrE-Text 与创新算法对比

### 8.1 实验目标对比

| 方面 | PrE-Text | 创新算法 v3 |
|------|----------|-------------|
| 核心目标 | 验证私有进化 + Bootstrap 两阶段生成 | 验证原型锚点个性化联邦提示词优化 |
| 隐私保护 | DP (clipping + noise) | DP (记账式) + KKT 投影 |
| 个性化 | 无 | 原型聚类 + 双层 Prompt |
| 冲突消解 | 无 | SVD + KKT 投影 |
| 注意力加权 | 无 | exp(R_k) softmax |

### 8.2 关键对比指标

| 指标 | PrE-Text | 创新算法 v3 |
|------|----------|-------------|
| 数据集 | Jobs/Congressional/Bioarxiv | Jobs |
| Scorer | Histogram (MiniLM) | DataInf / GradMM |
| 聚合方式 | 无聚合 | DBSCAN + Attention |
| 生成模型 | RoBERTa + Llama-2-7B | Llama-based |
