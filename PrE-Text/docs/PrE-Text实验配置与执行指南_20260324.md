## 七、评估阶段说明

### 7.1 Eval Small (DistilGPT2 微调)

- **状态**: 需要 `c4_checkpoint.pth` 文件（当前缺失）
- **解决方案**: 跳过此阶段，或使用无预训练的 DistilGPT2

### 7.2 Eval Large (LLaMA-2-7B LoRA)

- **状态**: 在 Windows 上受 PEFT + fp16 dtype 不兼容限制
- **解决方案**:
  1. **推荐**: 在 Linux 服务器上运行（安装 vLLM 可加速）
  2. **替代**: 使用 Flan-T5-3B 替代 LLaMA-2-7B（需要修改代码）

### 7.3 Linux 服务器运行指令

如需完整运行包括 Eval Large，在 Linux 服务器上执行：

```bash
# 安装 vLLM (Linux only)
pip install vllm

# 运行完整流程
cd /path/to/PrE-Text

python -m pretext_platform.scripts.run_pipeline \
    --config configs/experiments/paper_jobs_real_large_eval_eps129.yaml
```
