## 三、路径解析验证

### 3.1 相对路径工作机制

PrE-Text 使用基于配置文件位置的相对路径解析：

```
PrE-Text/
├── configs/
│   └── experiments/
│       └── jobs_real_eps129.yaml  ← 配置文件位置
└── outputs/pretext_platform/       ← 输出根目录
```

**路径解析链**：
- `repo_root()` = `configs/experiments/` 的父目录的父目录 = `PrE-Text/`
- `dataset_root()` = `repo_root / ../thesis_platform/datasets` = `PrE-Text/../thesis_platform/datasets` = `thesis_platform/datasets`

### 3.2 Linux 环境路径验证

在 Linux 服务器上，假设项目结构为：
```
/root/autodl-tmp/caiqiyue_file/
├── PrE-Text/
│   ├── configs/experiments/*.yaml
│   └── outputs/pretext_platform/
└── thesis_platform/
    └── datasets/
        ├── pretext_jobs/
        ├── pretext_forums/
        ├── pretext_microblog/
        ├── congressional/
        └── pretext_initialization_c4_en/
```

**路径兼容性**：✅ 正常

配置文件中使用的 `../thesis_platform/datasets` 路径在 Linux 服务器上能正确解析到 `/root/autodl-tmp/caiqiyue_file/thesis_platform/datasets/`。

### 3.3 注意事项

⚠️ **重要**：如果 Linux 服务器上 datasets 的实际路径与上述结构不一致（如在 `/root/autodl-tmp/datasets/`），需要修改配置文件中的 `paths.dataset_root` 为正确的绝对路径。

```
outputs/pretext_platform/
└── {experiment_id}/
```

## 九、切换到 Linux 环境后的注意事项

### 9.1 路径问题

**问题**：Linux 服务器上的 datasets 路径可能与 Windows 开发环境不同。

**解决方案**：
1. 确认 Linux 服务器上 datasets 的实际位置
2. 如有必要，创建符号链接：
```bash
# 如果 datasets 在 /root/autodl-tmp/datasets/
ln -s /root/autodl-tmp/datasets /root/autodl-tmp/caiqiyue_file/thesis_platform/datasets
```

### 9.2 模型路径问题

Linux 服务器上模型应位于：
- `/root/autodl-tmp/caiqiyue_file/thesis_platform/open_model/`

确认目录结构与配置一致。

### 9.3 vLLM 依赖

Stage 2 Bootstrap 在 Linux 上使用 vLLM 进行加速推理，如未安装会自动回退到 HuggingFace Transformers。

```bash
# 安装 vLLM（Linux 推荐）
pip install vllm

# 或使用 HuggingFace 作为备选（跨平台）
pip install transformers torch
```

### 9.4 CUDA 内存问题

22GB 显存的 RTX 2080 Ti 上：
- 可同时运行 2 个 PrE-Text Stage 1 实验（每个约需 8-10GB）
- Stage 2 Bootstrap 需要约 14GB（使用 LLaMA-2-7B）
- eval_large 使用 PEFT LoRA 约需 8-10GB

### 9.5 符号链接创建

建议在 Linux 服务器上创建必要的符号链接：

```bash
cd /root/autodl-tmp/caiqiyue_file/PrE-Text

# 创建输出目录软链接（如果有外部存储）
# ln -s /root/autodl-tmp/outputs ./outputs

# 创建数据集软链接（如果需要）
# ln -s /root/autodl-tmp/datasets ../datasets
```

## 十一、问题排查

### 11.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| `FileNotFoundError: datasets/...` | datasets 路径不正确 | 检查路径配置或创建符号链接 |
