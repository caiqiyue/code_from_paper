## 三、PrE-Text 实验配置

### 3.1 现有配置文件

| 配置文件 | 数据集 | Epsilon | 说明 |
|----------|--------|---------|------|
| `full_congressional_eps129.yaml` | Congressional | 1.29 | 完整实验 |
| `full_congressional_eps758.yaml` | Congressional | 7.58 | 高隐私预算 |
| `full_bioarxiv_eps129.yaml` | Bioarxiv | 1.29 | 完整实验 |
| `full_bioarxiv_eps758.yaml` | Bioarxiv | 7.58 | 高隐私预算 |
| `smoke_congressional_eps758.yaml` | Congressional | 7.58 | 轻量测试 |
| `smoke_bioarxiv_eps758.yaml` | Bioarxiv | 7.58 | 轻量测试 |
| `paper_jobs_real_large_eval_eps129.yaml` | Jobs | 1.29 | 论文配置 |

### 3.2 配置文件继承关系

```
full_congressional_eps129.yaml
├── base/paths.yaml
├── base/models.yaml
├── base/runtime.yaml
└── templates/noise_eps129.yaml  (sigma=11.3, epsilon=1.29)

full_congressional_eps758.yaml
├── base/paths.yaml
├── base/models.yaml
├── base/runtime.yaml
└── templates/noise_eps758.yaml  (sigma=2.31, epsilon=7.58)
```

### 3.3 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| rounds | 11 | 联邦轮数 |
| mask | 0.3 | Mask-fill 变异比例 |
| t_steps | 2 | 每个样本的 mask-fill 次数 |
| multiplier | 4 | 候选扩增倍数 |
| sensitivity | 8 | 每客户端最大样本数 |
| delta | 3e-6 | DP 的 delta |
| epsilon | 1.29 或 7.58 | 隐私预算 |
| sigma | 11.3 (eps=1.29) / 2.31 (eps=7.58) | 噪声标准差 |

## 八、注意事项

1. **GPU 需求**: LLaMA 模型需要足够显存，建议 24GB+ GPU

2. **运行时间**:
   - Smoke 测试: 10-30 分钟
   - Stage 1 完整: 2-4 小时
   - Stage 2 Bootstrap: 4-8 小时
   - Large Eval: 2-4 小时

3. **c4_checkpoint.pth**: DistilGPT2 小模型评测需要此文件，当前不可用

4. **congressional/bioarxiv 数据集**: 需要先下载，可能需要 1-2 小时（取决于网络）

5. **推荐顺序**: 先运行 Jobs/Congressional 的 epsilon=1.29 实验，再跑其他
