## 五、Linux后台自动执行审核

### 5.1 当前实现

**run_all_experiments.sh** 支持:
- `--dry-run`: 仅打印命令不执行

#### 方式1: nohup + &

```bash

tail -f logs/run_*.log
```

## 七、问题发现与修复

### P0 - 必须修复

#### P0-1: run_all_experiments.sh 日期命令兼容性问题

**问题**: `date -Iseconds` 在某些Linux发行版不可用

**影响**: 批量脚本无法生成正确的日志文件名

**修复**: 修改 `run_all_experiments.sh` 第225行:
```bash
# 原代码:
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

# 确认: date +%Y%m%d_%H%M%S 是标准命令，兼容性好
# 实际测试: 无问题，保持原样
```

#### P0-2: GLUE评估依赖HuggingFace在线下载

**问题**: `_load_local_glue_dataset()` 无法找到本地Arrow文件时，会fallback到HuggingFace在线下载

**影响**: 无网络环境下GLUE评估会失败

**影响级别**: 低 (服务器通常有网络)

**验证数据集位置**:
```bash
# 确认GLUE数据集是否存在
ls /root/autodl-tmp/thesis_platform/datasets/glue_sst2/formatted/
ls /root/autodl-tmp/thesis_platform/datasets/glue_qqp/formatted/
ls /root/autodl-tmp/thesis_platform/datasets/glue_qnli/formatted/
```

### P1 - 建议优化

#### P1-1: 缺少实验进度断点续跑支持

**问题**: 实验中断后需要从头开始

**建议**: run_experiments.py 可添加 `--resume` 参数检查已有输出跳过已完成阶段

#### P1-2: 缺少实验并行执行实现

**问题**: `--parallel` 参数声明但未实现

**建议**: 使用 `concurrent.futures.ProcessPoolExecutor` 实现并行
