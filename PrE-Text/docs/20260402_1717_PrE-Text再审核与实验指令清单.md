## 一、最终结论

### 1.1 设计覆盖结论

**结论一：从源码和配置覆盖性看，PrE-Text 已经可以覆盖设计文档中全部 PrE-Text 相关实验。**

这里的“PrE-Text 相关实验”指设计文档里明确由 PrE-Text 承担的实验部分，主要包括：

- 核心对比组：`GC2`、`GC4`、`GC8`、`GC9`
- 隐私-效用组：`GP1`、`GP2`、`GP3`、`GP4`

此外，当前仓库还额外补齐了：

- `forums` 的完整隐私系列
- `microblog` 的完整隐私系列
- `congressional` 的完整隐私系列
- 多种子统计入口
- 跨域迁移入口
- GLUE 多任务评测入口

因此，**PrE-Text 自身负责的实验集合已经有完整的配置和脚本入口，不再缺实验配置文件。**

### 1.2 当前本机可运行性结论

**结论二：当前这台机器“还不能直接开跑全部实验”，原因不是配置缺失，而是 Python 运行依赖缺失。**

本次实际预检结果表明，当前环境缺少以下核心依赖：

- `accelerate`
- `faiss`
- `numpy`
- `opacus`
- `sentence_transformers`
- `torch`
- `transformers`
- `sentencepiece`
- `datasets`
- `peft`

因此：

- **代码与配置层面：可完成**
- **当前本机运行环境层面：不可立即完成**

### 1.3 本地资源与联网回退结论

**结论三：PrE-Text 现在已经按要求收口为“只使用本地数据/本地模型”，不会因为本地资源缺失而自动去 HuggingFace 在线下载。**

本次已再次确认并修正：

- `eval_small/gpt2_eval.py` 不再允许 `local_files_only=False`
- `glue_classification_eval.py` 不再回退到 HuggingFace 在线加载数据集
- `run_glue --validate` 现在只检查本地数据集
- 当前本地 `rotten_tomatoes` 已存在可离线使用的 `raw DatasetDict`

因此，**如果本地数据或本地模型不存在，当前代码会直接报错或在 preflight 阶段拦截，不会联网下载。**

```bash

  --stage stage1
```

可选阶段：

- `stage1`
- `bootstrap`
- `eval`

### 8.3 跨域迁移

示例：Jobs -> Forums

```bash
python -m pretext_platform.scripts.run_cross_domain \
  --source-config configs/experiments/jobs_real_eps129.yaml \
  --target-dataset forums
```

含义：

- 用 source config 跑 source stage1
- 再跑 source bootstrap
- 把 source 合成语料复制到 target 评测目录
- 对 target dataset 执行 target-domain evaluation

输出位置：

- `outputs/pretext_platform/cross_domain/jobs_to_forums/`
- `cross_domain_summary.json`

含义：

- 复用该实验已经生成好的 Stage 2 合成语料
- 对本地 GLUE 任务做分类评测

输出位置：

- `outputs/pretext_platform/jobs_real_eps129/eval_glue/`

- `stage1 requires missing Python modules: accelerate, faiss, numpy, opacus, sentence_transformers, torch, transformers`
- `stage2 requires missing Python modules: sentencepiece, torch, transformers`

因为本次静态审计已经确认：

- 16 个主配置存在
- 对应本地 train/eval/init 数据存在

- 实验输出路径已经固定
- 结果汇总路径已经固定

因此，当前唯一缺的只是**本地离线 Python 运行环境**。
