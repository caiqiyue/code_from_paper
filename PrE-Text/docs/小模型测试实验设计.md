# 小模型测试实验设计

> 生成时间：2026-04-05
> 目的：使用小模型（不会OOM）验证代码逻辑，排除 GPU 显存不足导致的问题

## 背景

当前测试发现：
- **大模型问题**：eval_large 使用 llama_2_7b_hf (~14GB fp16) + PEFT LoRA 在 22GB GPU 上因 dtype 不兼容失败
- **已验证通过**：Stage1、Stage2、eval_small 都能正常完成

## 已完成的代码修改

为支持小模型测试，已进行以下代码修改：

### 1. `pretext_platform/core/preflight.py`

**修改位置**：第 73-79 行

**修改内容**：允许 `distilgpt2` 作为 Bootstrap 的生成器模型

```python
# 修改前
if generator_model == "llama2_7b":
    stage2_modules.add("sentencepiece")
else:
    raise ValueError(
        "bootstrap.generator_model must be 'llama2_7b' on the fixed Linux server."
    )

# 修改后
if generator_model == "llama2_7b":
    stage2_modules.add("sentencepiece")
elif generator_model != "distilgpt2":
    raise ValueError(
        "bootstrap.generator_model must be 'llama2_7b' or 'distilgpt2'."
    )
```

### 2. `pretext_platform/algorithms/bootstrap.py`

**修改位置**：第 208-213 行

**修改内容**：支持使用 `distilgpt2` 路径进行 Bootstrap

```python
# 修改前
if bootstrap_model != "llama2_7b":
    raise ValueError(
        "Stage 2 bootstrap only supports generator_model='llama2_7b' on the fixed Linux server."
    )
model_path = model_paths.llama2_7b

# 修改后
if bootstrap_model == "llama2_7b":
    model_path = model_paths.llama2_7b
elif bootstrap_model == "distilgpt2":
    model_path = model_paths.distilgpt2
else:
    raise ValueError(
        f"Stage 2 bootstrap only supports generator_model='llama2_7b' or 'distilgpt2', got '{bootstrap_model}'."
    )
```

使用小模型（distilgpt2、gpt2、qwen_2_0_5b_instruct）设计测试实验，验证：

## 预期结果

### 如果所有小模型测试都成功，说明：
- 代码逻辑层面没有其他问题
- 问题仅存在于 llama_2_7b_hf + PEFT LoRA 的 dtype 兼容性
- 在更大显存的 GPU（A100 40GB+）上可以直接运行正式实验

### 如果小模型测试失败，说明：
- 存在其他代码层面的问题，需要进一步排查
